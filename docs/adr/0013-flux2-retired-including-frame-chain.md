# Flux.2 全链退役（含帧链）

issue #40（c879400）从资产图链移除 Flux.2 时**明文保留**帧链的 Z-Image/Flux.2 双模型产物（提交信息：「该纪律对 frame 链仍有效，不能照删」）；2026-10-18 用户确认 Flux.2 模型已物理删除，保留双模型等于每次为帧提示词多付一份无人消费的重写费用、向导还多问一整轮「Flux.2 画布」，原「帧链保留」裁定的前提已消失。故**帧链一并退役**：画布默认表删 flux2 行（选择器随家族表自动收缩，少问一整轮）、帧提示词改单模型（Z-Image）输出、flux2 输出键与「两模型分别重写」纪律删除、生图请求【画布】块只渲染现存家族。构图词**不**跟着删：分套绑画幅族、不绑模型（issue #42 既定），用户选正方画布时仍走正方构图套；docs 里「按模型分两套」的旧叙述随之更正为画幅族口径。

被否决的方案：只清资产侧残留、帧链继续出 Flux.2 版（模型已删，产物无消费者，纯烧 token——今天实测的多余提问正是这种半截清理的残留）；连正方构图套一起删（它绑画幅族不绑模型，删了会伤未来正方画布的构图词）。旧产物/载荷里的 flux2 键按既有弃读惯例处理，不做静默兼容；brief 文件同义键 `画布 flux2:` 开始报「未知生图模型」，属预期。
