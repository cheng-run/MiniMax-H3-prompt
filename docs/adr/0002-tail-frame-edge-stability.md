# 尾帧边缘稳定性采用生成端约束 + 参考帧锐度优选双防线

H3 生成的视频在运动时可能产生人物轮廓波纹/边缘抖动，剥作下一段 `first_frame` 参考的尾帧也因此带波纹，下一段的人物识别会失败（人物对不上、认不出）。

防线一（生成端，治本）：每个 `[Shot N]` 块结尾原样注入边缘稳定约束句（保人物剪影/面部轮廓/服装边缘锐利、无波纹/扭曲/边缘抖动），注入点覆盖 LLM 整体生成为 base 规范（`references/base-en.txt`）与逐段重写指令（`_REWRITE_INSTRUCTION`），机械拆分路径在 `split_shots_from_prompt` 兜底附加。

防线二（参考帧侧，兜底）：尾帧剥离不取最后一帧，改取尾部最后 5 帧中 Laplacian 方差（锐度）最大的一张作桥接帧；全部低于阈值（运动模糊中）则回退最后一帧并告警。

关键事实：桥接帧只作为下一段 H3 参考输入，**不进入成片时间线**——成片用各段视频自身的帧拼接，因此选取倒数第几帧都不会造成成片跳接，只影响下一段首帧的姿态提前量（毫秒级），是安全的。
