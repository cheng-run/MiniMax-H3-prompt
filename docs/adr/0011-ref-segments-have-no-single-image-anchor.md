# 多参分段不套单图开场锚——issue #9 裁定的适用范围止于首尾帧链

issue #9 裁定「分段提示词恒用单图开场锚（I2VA 行）」，读起来像「所有分段」的通则，但它的理据整条是首尾帧链的：每段只喂一张图（桥接帧/首帧）、喂进 first frame 槽、尾帧要锐利留给下一段（edge-stability 句的官方理由）。多参（ref2va）分段没有桥接帧、没有帧槽可锚（issue #46）——锚定由**全片共享同一批参考素材**承担（每段重复 subject_definitions/retention_analysis 定义），叙事对位由**时间轴注记＋起止状态声明**承担。故多参分段**不得**出现 I2VA 锚定行（`validate_ref_segment` 不查对齐指令，写段指令明令禁写），issue #9 的裁定原文不改、适用范围在术语表「分段锚定行」钉明。

被否决的方案：给多参段也套 I2VA 行（会声明用户不喂的 `Picture 1` 帧槽，纯幻觉接线）；把 issue #9 扩成全局通则（等于把桥接链语义强加给没有桥接的路线）。同裁定的实现侧事实：定义性段落由组装器逐段重复整片原文（不让 LLM 重写，标签语义一致是代码性质），时间轴注记/起止状态声明由组装器注入 canonical 形态（校验器同源检出）。
