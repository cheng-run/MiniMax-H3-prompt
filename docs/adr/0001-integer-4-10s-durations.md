# 段时长必须是 4-10 秒整数，末段吸收余数

ComfyUI 的 H3 时长下拉只有 **4-10 秒的整数档**，没有小数选项。段时长若出现小数（如 4.50s）或越出 4-10s 区间，用户在工作流里根本选不出来，直接导致该段无法执行。

因此强制执行：提示词侧 `[Shot N]` 时间为整数秒（`At MM:SS.000`），拆分后校验；执行段侧 `split_shot_into_segments` 把 `Shot` 均分后统一取整，前段取整、**末段吸收余数**，保证所有段加起来严格等于总时长且只有末段可能不合典型长度（越界时递归增减段数拉回区间，仍拉不回则打印警告交给人工调总时长）。

替代方案（等分保留小数、或用 10 秒完整段）要么产出现实中选不了的时长，要么在末段吸收余数上无法保证总和守恒。取整时 `min_segment_seconds=4.0`、`max_segment_seconds=10.0`（config 的 SEGMENT_CONFIG 已同步）。
