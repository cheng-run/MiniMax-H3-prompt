# 电影语言知识内联进提示词、不做 skill 运行时

2026-09-27（issue #31/#30）。

## 背景

用这个工具生成的视频「没有水平」可指到具体空缺：镜头里只有「发生了什么」，没有景别、机位角度、构图、光线的取舍。用户为此做过一轮调研，产出 `docs/film-language-playbook.md`（403 行：词表、写法骨架、写作纪律、真实坏样本的前后对照）——**但代码一行没动**：知识停在文档里，流水线读不到。

用户起初的想法是「把那几个 skill（如 `h3-prompt-writing`）装进项目工作流里的 agent」。这一条得先钉死。

## 裁定一：不装 skill，也不自建 skill 运行时

**流水线角色是一次纯 API 调用**：`create_agent(model=…, system_prompt=…, tools=…)`。没有工具、没有按需加载、没有「先看目录再决定读哪个文件」的机会。全仓只有三处会把**文件内容读进模型请求**——角色提示词目录（`agents.load_role_prompt`）、分段规划师提示词（`segment_planner._load_instruction`）、澄清器提示词（`clarification.CLARIFY_PROMPT_PATH`）；`skill` 一词在代码里**零命中**。（读文件的地方远不止三处，会话落盘、brief 解析、产物读写都在读——但那三处才是「知识进到模型眼前」的边界，本裁定针对的是它们。）

仓里唯一一次「vendor 官方 skill 参考文件」的先例（`references/base-en.txt`、`ref-en.txt`）**从不被任何代码打开**——是先例性的空接线，不是成功先例。所以「装」在本仓没有对应形态；有价值的是**把知识接进那几个真被模型读到的文本**。

`agents/__init__.py` 已记过同族的教训：deepagents 无条件注入 `ls` / `write_file` / `execute` 等内建工具，结果是「模型去调 `write_file` 而不是直接返回文本，导致空产出」。给角色配工具来「按需读词表」会重新踩进同一个坑。

## 裁定二：真源是内联的单一来源，由读取口按消费者取切片

| | |
|---|---|
| 真源 | `src/minimax_h3_prompt/knowledge/film-language-video.md`（视频半，双语） |
| 读取口 | `film_language.video_slice(consumer)` |
| 调用处 | `agents.load_role_prompt`（角色提示词加载口） |

**为什么切片而不是整份**：分镜师定景别与构图，摄影指导才写光线与机位角度。整份灌给所有角色既浪费上下文，也会让不写光线的角色去挑光线词。**不声明即拿不到**——加白名单是显式动作，不会悄悄扩权。

**为什么附在加载处、不抄进各份 `.md`**：词表是逐字读入的纯文本，抄进每个角色就是 N 份硬拷贝，各自漂移。同一个理由推翻了 `storyboard.md` 里原先手抄的那份机位白名单（本票一并改成指针）。

**为什么真源里没有花括号**：加载链上没有模板引擎，真源是逐字读入的——含花括号既无用处，又给将来任何插值留下坑，故由测试钉住。

**为什么和官方 references 分开存放**：两者**分工不同**——词表管「选哪个词、句子怎么落」，官方规范管「字段与结构」。格式问题一律以官方规范为唯一依据。术语见 `CONTEXT.md` 的「电影语言词表」。

## 裁定三：要逐字符照抄的官方原文只留指针

真源里**不出现** edge-stability 句与帧变体锚定行的原文，只写「去 `h3_validator.EDGE_STABILITY_SENTENCE` / `h3_validator.ALIGN_TEMPLATES` 取」。

甄别判据是「**该处提示词现在有没有**」，不是「校验器管不管」：校验器是闸门不是指导，而 edge-stability 那条**只是 warning、从未拦到过**（9 份真实产物该句出现 0 次）。

## 考虑过并放弃

- **装外部 skill / 自建 skill 运行时**：见裁定一。角色没有工具，加载链上没有模板与插值。
- **把词表抄进各角色 `.md`**：同一份词表 N 份硬拷贝，改动要改 N 处、漏一处不报红。
- **让角色用工具按需读真源文件**：给角色配工具会重演 deepagents 那次「去调工具而不是直接产出文本」的空产出。
- **整份真源灌给所有角色**：噪声 + 越权（分段规划师拿到审美词，段尾钩子就不再是可判定的末态声明）。
- **给分段规划师也加词表**：`end_hook` 是锚帧语义校验的对照物，掺审美词会让人工判定不可判。
- **顺手收紧闸门**（如把「切点整秒」加进 validator）：本仓纪律是闸门收紧要先有实测样本，见 ADR 0003 的对称纪律。本票只记录、不主张。
- **为这次改动新增校验器规则**：同上。到达性由测试钉住，产出质量由人工读。

## 后果与边界

- 真源会持续微调，测试只钉「切片到了没有」（断言真源标记串），不钉内部措辞。
- 本票只接**选词侧**两个角色（分镜师、摄影指导）。落笔侧（整片提示词工程师与两条写段路径）与生图侧各由后续票接同一读取口——`VIDEO_SLICES` 加白名单是显式动作。真源里的「词表：风格」当前无人取，是留给落笔侧的。
- **不新增任何闸门**：本模块只负责把词送到，不管产出好坏。
