# base 段写动机不再投料：三臂实验结论与边界

> **状态（2026-11-20 复核）**：已接受；随 #355 收口，父 spec #349。本文把「base 段写动机」这条线的结论与证据边界就地记下，供下一轮不必重开。**不改任何代码**——`MOTIVE_DISCIPLINE_BASE` 文本原样留仓。

## 背景

spec #349 把动作动机分三层：#351 共享编剧层（**产物层有效**，新会话 `script.md` 长出带来源的动机条目）、#353 base 段写弱化版注入、#354 验收。#354 两轮实测（同会话、同 plan/state/分镜表，只换纪律文本）**都是严格判据 0/20**：第一轮原弱化版措辞 0/20，第二轮补回导演台原版「这类说明是要落进画面的意图」框架后仍是 0/20。

#355 把这事从「继续调措辞」改成**只读三臂实验**，先定阈值后跑，看「换载体或换写作机制」能不能改变 base 段词的动机密度。实验物证全部在 `output/accept-355/`（`prereg.md` 预登记、`report.md` 读数、`segments/` 18 段、`requests/` 18 份请求全文）。

## 决定

1. **base 侧不再往动机纪律里投料。** 三臂（对照／注入动机块／换「没做的选择」纪律）都未过预登记门槛（`min(两轮 M-剧) ≥ 3` 且两轮 ≥15%）。对照臂两轮均 0 句（动作句各约 18／20）与 #354 一致；注入动机块臂 2、4 条；「没做的选择」臂 3、5 条但 r1 约 14%，落在预登记未覆盖的中间格，按预登记口径未过门槛（缺口已如实记在 `report.md §四`，未事后补判据）。

2. **模型的「怎么做」写得好、「为什么做」写不出来。** 这是实验最稳的观察：三臂的段词都把动作分解到「`the strap and not the pack body`」「`two finger-widths`」这一级精度（#355 段词原句），却几乎不把分镜表的「这镜揭示了什么」用意句编码进动作句。补回导演台框架（#354 第二轮）也只让约束更精确，没让动机出现。**这不是措辞问题**——换载体（注入编剧层原句块）与换机制（点名被放弃的选项）才是唯一让戏剧动机句出现的两种做法，且量都低。

3. **「没做的选择」纪律是唯一可复现的机制，但产量低，不落地。** 8 条 M-剧句**全部**是预登记 §3.1 预测的「点名被放弃的可见选项」对照式（`leaving the wider inland lane … unused` / `rather than cutting to the shorter inner line` / `instead of stepping up onto the top of the edge`），跨 3 段、两轮都出现——按设计生效，不是偶发。代价是它只产出约 14–24% 的动机句，且会改动 base 已交付产物的措辞。按用户 2026-11-20 裁定，走收口不落代码。

4. **注入编剧层原句块（臂 B）不稳定。** 两轮 2 条 vs 4 条，差两倍，且都靠模型「自发」把用意句翻译成 `as if / stretches / without a destination` 一类措辞——注入动作本身不强制这一步，所以同一臂两轮不稳。它也不是免费的：把编剧层动机条目塞进写段请求，等于让写段器读一份它原本不读的产物。

## 考虑过的备选

- **把措辞再调一轮**：#354 已经两轮只换措辞、结论不变。继续调是「为改而改」，没有新理由。
- **落「没做的选择」纪律**：机制可复现，但产量低（14–24%）、改动已验收产物措辞、r1 未过门槛。收益不足以抵消两样代价。
- **注入动机块进生产**：不稳定（两轮差 2 倍），且要求 base 写段器读编剧层产物——与「写段读分镜表与剧情概述、不读剧本」的既有事实源边界冲突。

## 后果

- `MOTIVE_DISCIPLINE_BASE` **原样留在仓里、原样注入 base 两条写段路径**——它是「取不到动机就写无动作状态、不为动机发明事实源没有的动作」的**钳制**，这条钳制仍有价值（防模型为填时长编动作）；本文只裁定**不再追加投料去提高动机句产量**，不撤现行纪律。
- `CONTEXT.md` 的「不迁清单」补一条指针（动机纪律 base 做的结论与本文）；基线文档 `docs/research/2026-11-19-动作动机改前基线.md` 追加本实验末节。
- ref 与导演台的写段请求**逐字节不变**（本实验只读、只跑 base 的 v2 路径，未碰另两条路线的请求）。
- 「动机是否进术语表正式词条」仍不做（spec #349 的 Out of Scope 不变）。
