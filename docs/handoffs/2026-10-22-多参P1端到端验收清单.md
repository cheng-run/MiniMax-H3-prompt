## 二、跑一次 24 张的完整多参流程

用一次真实 brief（素材需求 ≥24 张）走向导的多参路线，直到成片。沿途确认下面四类信号。

### 1) 步骤横幅（每个长步骤开头一行）

形如 `▶ 正在……（第 N/M 轮）……`。应至少在这些位置看到：

| 位置 | 横幅 |
|---|---|
| 阶段 1 开始 | `[阶段 1] 正在生成剧本、设计与资产图生图提示词`（多参版，**不含「首尾帧」**） |
| 素材循环：选择之后 | `▶ 正在与前序素材对齐（第 1/1 轮）……` |
| 素材循环：出词 | `▶ 正在生成生图提示词（第 1/1 轮）……` |
| 读图校对 | `▶ 正在读图校对（第 1/1 轮）……` |
| 素材改写 | `▶ 正在改写生图提示词（第 1/1 轮）……` |
| 阶段 2 拆段 | `▶ 正在按镜头切点拆分执行段（第 1/1 轮）……` |
| 逐段写段 | `▶ 正在写第 N/M 段（第 N/M 轮）……`（每段一行，写完立刻出该段正文） |

### 2) 等待心跳（长时间无输出时）

形如 `⏳/…/⏱/↻`。正常流程里至少应看到「已有响应（首字节 Xs）」或「生成中（N 块 / kB，已等 Xs）」；
若网关卡住，应看到「判定卡住（第 N 次尝试）」或「正在重试第 N 次」——
**看到它们就说明看门狗生效了**，把这几行原样抄下来更有价值。

### 3) 槽位映射

- 注入卡（`output/sessions/<会话>/GEN001/injection-card.md`）应逐条列出
  `<Picture 1>` → `ref_image_0` …… `<Picture 24>` → `ref_image_23`。
- 第 25 张（若剧本需要）应标「无对应槽位」并在告警里给出「去扩工作流端口」的指引。
- 素材菜单顺序、注入卡顺序、工作流槽位顺序三者一致（菜单行形如 `1. <Picture 1> 名字（人物）`）。

### 4) 逐段写一段出一段

- 段 1 的正文出现 → 你生成并交回 → 通过后才应出现段 2 的正文（**不能提前看到段 2**）。
- 每段正文之前应有「正在写第 N/M 段」横幅；写段失败时应看到病因与尝试次数，而不是只写「跳过」。

## 五、已知边界（不是失败）

- ≤15s 的单段直出不做拆段，段文件由交付时落盘（不走「按需写段」）。
- 非流式回退路径上**只能报已等时长**（网关不支持流式时才会走到），这是 ADR 0019 的裁定。
- 成本表数字会因直调路径开始记账而上升，属预期变化。
