## 已确认的 D1 决策

以下决策已经用户逐项同意；若继续写 D1 spec，应保持这些边界，不要重新发明：

- D1 是**最小纵向切片**，不是空壳：Vue 应用、真实 FastAPI health 接口、生成客户端、组件、测试、构建、CI 全部接通。
- 前端是单个 `frontend/` package；根仓是 Python + 前端的 monorepo，暂不拆 `apps/`、`packages/` 或 Turborepo。
- Node 24 LTS、pnpm 11、Vite、Vue 3 Composition API、TypeScript strict、`vue-tsc`、ESLint flat config、Prettier。
- 开发期 Vite proxy 到本地 FastAPI；生产期 FastAPI 同源托管 `frontend/dist`；浏览器统一访问 `/api/v1/...`，默认不引入 CORS。
- Pinia 只保存客户端 UI 状态；TanStack Vue Query 管理 REST 服务器状态；生成会话、执行任务、人工待办和产物的权威状态归 Python。
- D1 的 API 契约链：FastAPI 唯一真源 → 提交 `contracts/openapi.json` → `openapi-typescript` 生成 `frontend/src/api/generated.ts` → `openapi-fetch` 运行时 → 所有请求经 `frontend/src/api/client.ts` → CI 做 drift check。
- API 错误统一 RFC 9457 `application/problem+json`；成功响应直接返回资源，不使用 `data` 包装。
- Vue Router 使用 `createWebHistory`；FastAPI 对非 `/api` 未知路径回退 `index.html`。
- 样式使用 CSS custom properties、全局 reset、Vue scoped CSS；D1 不引入 Tailwind、UnoCSS、SCSS、Storybook 或完整 UI 套件。
- D1 测试：Vitest + Vue Test Utils + MSW；Playwright 走真实 FastAPI + 构建产物 + SPA fallback；覆盖门禁为行/函数 ≥ 80%、分支 ≥ 70%。
- CI：新增 `frontend-quality`（`ubuntu-latest`）和 `frontend-e2e`（`windows-latest`）；保留现有 Python `check`（`windows-latest`）。D1 不调用真实 LLM、ComfyUI、ffmpeg 或外部模型服务。
