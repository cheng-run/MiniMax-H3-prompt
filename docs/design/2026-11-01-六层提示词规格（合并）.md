## 1. 问题陈述

导演台四条路线（t2v／i2v／fl2v／r2v）的提示词，现在**每一层都是凭经验写成、没有可引用的依据**：
同一件事在角色提示词、机读真源、模型档纪律三个地方可能各说各话；写坏了也说不清坏在哪一层。

六张决策票已经把「怎么写、依据是什么」逐层问完了，产出是五份层规格 ＋ 一份判据表 ＋ 一份真源结构决定。
**但六份文档合在一起立刻暴露四类问题**，这正是本票要解决的：

1. **跨层打架**：同一段文本同时被两层持有（`qwen.md` 既管关键帧又管资产图；`film_language.py` 的白名单既被结构决定又被动；`tailframe.py` 既插切片又改正则）。
2. **真缺口**：#119 决定的尾帧真源**没有出现在 L4 的改动清单里**——单看 L4 看不出来。
3. **顺序不清**：谁能先落、哪些改动必须同一次提交、违反会怎样，六份文档各说一段，没有一处合起来说。
4. **验收口径分散**：每个层规格都有「可机械检查清单」，但没人说过这些清单**现在做不做**。

## 2. 方案

把六份文档收敛成 **7 个改动单元**（U1–U7），每个单元＝**一次提交**、可独立验收：

| 单元 | 层 | 一句话 |
|---|---|---|
| **U1 剧情** | L1 | 四个角色 `.md`，把「形式行」三跳链路打通（纯文本，无代码） |
| **U2 视频词与运镜** | L2+L3 | 三字段恢复＋路径结构＋运镜四条判据进真源＋导演台形状闸翻正向 |
| **U3 尾帧编辑链** | #119 + L4 | 新建尾帧真源与读口，然后才是尾帧写法与三份编辑纪律 |
| **U4 关键帧** | L5 | 八步骨架落角色提示词，只落这一处；哈希基线同提交 |
| **U5 资产设计与写词** | L6-a | 母版清单由设计端声明、写词端照单出词（同一提交） |
| **U6 定义块 refdefs** | L6-b | 多图一 Subject 的请求措辞＋warning（同一提交） |
| **U7 路由与素材循环** | L6-c | 人物类不自动切 MOSS；审查加一句人审问句 |

单元间的**强制同提交**关系共 5 条，全部来自「同一文件／同一契约被两处持有」：

1. `U2` 内：真源措辞 ＋ 写段请求块 ＋ 形状闸（同一提交，否则闸与写法互相判死）
2. `U3` 内：#119 的真源＋读口＋插入点，与 L4 的正则＋报错文案＋角色提示词（**同一文件 `tailframe.py`**）
3. `U4` 内：`frame_prompt_engineer.md` ＋ `qwen.md:8` 适用范围 ＋ 哈希基线
4. `U5` 内：`character_designer.md` ＋ `image_prompt_engineer.md`（L6-17）
5. `U6` 内：`refdefs.py` 请求措辞 ＋ warning（L6-18）

## 3. 用户故事

1. 作为**用导演台出片的创作者**，我想让每段视频词都写成官方三字段，这样片子的环境声与配乐不再糊成一片。
2. 作为创作者，我想让 fl2v 段的最后一个镜头真的落到我给的尾帧那张构图，这样段与段之间看起来像同一部片子。
3. 作为创作者，我想让尾帧图像是「把第一帧改一改」而不是「重新画一张」，这样人物同一张脸不会在接缝处换人。
4. 作为创作者，我想让尾帧的位移写成看得见的地标关系，这样「原地踏步」这种失败能当场看出来。
5. 作为创作者，我想让关键帧正文短到 400–500 词、带位置短语与整帧收尾句，这样画面不会被稀释。
6. 作为创作者，我想让画面里必须可读的字不超过两条、其余写成模糊，这样不会凭空长出一块招牌。
7. 作为创作者，我想让人物参考图继续用拼板母版，而不是被拆成一图一视角，这样我一个角色不会占掉 3–5 个图槽。
8. 作为创作者，我想让同一个角色的三张母版在定义块里被认成同一个主体，这样模型知道这是同一个人。
9. 作为**接票的实现工程师**，我想拿到一份「改哪个文件的哪几行、依据是哪条」的清单，而不是六份互相引用的长文。
10. 作为实现工程师，我想明确知道哪些改动必须同一次提交，这样我不会改了一半就让旧校验器判死新写法。
11. 作为实现工程师，我想明确知道哪些东西**不许动**（八步不进 `qwen.md`、`film-language-image.md:31` 不改、`h3_validator` 不碰），这样我不会顺手改坏两个消费者。
12. 作为实现工程师，我想知道改完要跑哪些用例、看什么信号（不只是「绿了」），这样我不会把真发网络的慢用例当成卡死。
13. 作为**审片人**，我想有一套二值判据＋固定基准片，这样两次改动之间能比。
14. 作为审片人，我想让剧情层不跑片、只做文字评审，这样基准片不会因为剧情一改就换掉。
15. 作为**维护者**，我想让每一层都能指回它的依据等级（官方／文献／社区一手／社区经验／本仓实测），这样下一轮不会把社区经验当成官方。
16. 作为维护者，我想让明确不做的项（自动评分、流程改造、二期模式）写在一处，这样下一轮不会重新讨论一遍。
