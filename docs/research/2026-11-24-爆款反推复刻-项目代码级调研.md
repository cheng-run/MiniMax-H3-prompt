## 0. 结论先行

1. **没有现成项目能产出 MiniMax-H3 提示词**。唯一真有一份 H3 请求契约的是 hypit（`packages/minimax-h3/README.md:14-18`），但它只是「请求语义 + 校验」，不含拆解、不含提示词编译。
2. **星数与本领域的实现密度无关，甚至负相关**。31k 星的 hypit 没有「视频 → SVML」转换器；15.8k 星的 openmotion 分析层极薄；**11 星的 video-break-agentkit 是全批代码价值最高的一个**；4 星的 3dudu 贡献了最清晰的分类契约。
3. **三块核心能力在 14 个仓库里全部缺位**：真实词级时间戳与镜头→词区间对齐、变体/成本引擎、"拆解产物 → 生成提示词"的编译器。这三块必须自己写。
4. **最值钱的单个设计是 hypit 的语义锚点时间模型**（`packages/narrative/src/types.ts:1-70`）：秒是投影结果，词区间才是真值。复刻换文案时秒会漂，词锚不会。
5. **最强的反幻觉手段不是 prompt，是结构**：两态测量（`measured`/`unresolved`）、证据与真相分离、跨模态域冲突、截断检测、AI 输出全字段归一化。五条各自都有可直接照搬的实现。

## 2. L1 确定性事实层（不调 LLM 决策）

这一层是全批项目里**实现最扎实**的部分，几乎全部可直接移植。

| 机制 | 出处 | 为什么值 |
|---|---|---|
| **切点三段兜底链**：`select='gt(scene,X)'` → 去重（首帧 0、尾帧=时长、最小间隔 0.45s）→ 按步长抽稀到 max-shots → 检测为空则 2s 等距回落；并记 `detection_mode` 区分 `scene_detection` / `fallback_interval` | `video-shot-analysis-feishu/scripts/extract_shots.py:38-91`、`:207-214` | 唯一完整处理「检测不到怎么办」的实现；MIT 可改可用 |
| **切点候选：32×32 RGB 逐字节绝对差**，除以 255 得 score，采样 12/s，默认阈值 0.1 | `hypit/packages/media-local/src/files.ts:470-493` | 无依赖、可解释；比直方图更轻 |
| **切点：HSV 三通道直方图 + Bhattacharyya 距离**，8fps 采样、阈值 0.26、最小间隔 0.6s、末尾短段剔除 | `ViralForge/scripts/analyze.py:43-89` | 比逐像素帧差稳 |
| **光流算运镜 + Sobel 纹理掩码**：`tex = hypot(gx,gy) > 40` 过滤无纹理像素，再分别取 `median(u)`、`median(v)`、`median((u·x+v·y)/r²)`、`median((v·x−u·y)/r²)` 得 pan/tilt/zoom/rotate；按阈值分类成 push_in/pull_out/move_*/roll-orbit/static，按 speed 分 still/slow/medium/fast | `reelmimic/.claude/skills/video-clone/scripts/analyze.py:186-204` | 黑场与静态 UI 条会把中位数拉到 0，这个掩码是必需品 |
| **逐行时间方差找录屏有效带**：`var = std(axis=0).mean(axis=1)` 找变化最剧烈的那条带 | `reelmimic/.../analyze.py:88-100` | 专治「上下是 UI 带、cropdetect 看不见」的手机录屏 |
| **测量只给两态**：特征不足 8 个直接 `unresolved` + `reason`，不给凑数值 | `openmotion/scripts/measure_motion.py:36-58`；`register_motion.py:44-58`（inlier<12 或 ratio<0.3 判 unresolved） | 最廉价的反幻觉：宁可说「测不到」 |
| **BPM 自相关 + 70/180 倍频折半纠正** | `ViralForge/scripts/analyze.py:141-158` | 多数实现漏这一步，48–60 / >180 BPM 的曲子会被倍频错判 |
| **0.5s 窗 RMS 当能量曲线** | `ViralForge/scripts/analyze.py:173-180` | 轻量替代，够用 |
| **ffmpeg 三级回退**：env → PATH → `imageio-ffmpeg` 内置；ffprobe 缺失时解析 `ffmpeg -i` 的 stderr，且注释写明**不能加 `-v error`**（会屏蔽 Duration） | `video-break-agentkit/tools/process_video.py:_resolve_ffmpeg_paths` | Windows 上直接可用 |
| **固定时长阶梯分段**：`0-3 / 3-5 / 5-10 / 10-20 / 之后每 10s`，**故意不做镜头检测** | `video-break-agentkit/tools/process_video.py:_build_segments` | 与「按场景切」完全不同的产品判断：前 3 秒本身就是短剧的独立单元 |
| **每段按比例取 3 帧，末尾留 0.1s 安全边距** | `video-break-agentkit/tools/process_video.py:_extract_segment_frames` | 避开末帧解码失败 |
| **数据质量三级** `complete/partial/failed` + 字段级 missing 列表；补充只填空字段、不覆盖已有值 | `blogger-distiller/utils/quality.py:check_note_quality`、`merge_note_supplement` | 抓不全时如实降级，而不是静默编 |
| **写盘前脱敏、跨条同编号、幂等** | `blogger-distiller/utils/privacy.py` | 合规做成代码而不是声明 |

### 音频侧三个真实坑（reelmimic docstring，`analyze.py:22-26`）

1. **立体声要分 L / R / L+R 三次测**——反相相加会互相抵消。
2. **必须 `loudnorm`**——否则节拍跟踪看到的是底噪。
3. **手机录屏要 `cropdetect` 裁 UI 带**，且 cropdetect 有时看不见，需要 §2 的逐行方差法兜底。

### 长视频性能

`reelmimic/analyze.py:150-156` 用 `ProcessPoolExecutor` 分片并行，注释写明「seeking a long video is the slow part」——不是解码慢，是 seek 慢。

### 两种截然相反的产品判断（都成立，取决于场景）

- **不做镜头检测，用固定时长阶梯**（`video-break-agentkit`）：因为短视频的前 3 秒本身就是独立叙事单元，检测反而切碎。
- **先高精度切点再逐镜读图**（`feishu` / `reelmimic`）：因为要逐镜做运镜测量和时长统计。

选择依据是**下游要什么**：要「钩子分析」用前者的阶梯；要「运镜复刻」用后者的切点。

## 5. L3 IR：结构中间表示

### 5.1 hypit 的语义锚点（本批最值钱的设计）

`packages/narrative/src/types.ts:1-70` 定义了四层：

```text
NarrativeToken     — 带 startAnchorId / endAnchorId
NarrativeSegment   — 带 tokenStart / tokenEndExclusive
SemanticAnchor     — 四种 kind：segment-start | segment-end | token-start | token-end
NarrativeMoment / NarrativeSelection — 按语义选出的点与区间
```

**秒是投影结果，不是真值**：`packages/narrative-temporal/src/projection.ts:11-30` 的 `projectDomainFrame(domain, window, timeline, ...)` 把语义锚点投成帧号，并校验 `boundary.frame <= timelineFrameCount`。

SVML 文件的真实形态（`examples/interview/reference.svml:26-40`）：

```xml
<script id="story">
  <manifest-rule>
    <BOY>Hey yo! || Is this || Lamborghini || yours?
    <WIFE>Mmm hmm.
    <BOY>Give me || three rules || to make your || first million.
    <WIFE>OK || the || first one || is || @{manifest!} Manifest.
```

- `<manifest-rule>` = Segment（可演出的段）
- `<BOY>` / `<WIFE>` = Role Cue（说话人）
- `||` = Caption Cue 切点（字幕换行）
- `@{manifest!}` = Moment（语义事件点，供图形/音效响应）
- `@{proof}...@{/proof}` = Selection（语义区间）

素材用引用表达而非路径：`<gpt:Image id="shared-view" .../>`（`reference.svml:92`），下游 `<gpt:Reference image={shared-view.image}/>`（`:98`）。
