## 1. 方法

对每份产物 PNG 的 `prompt` chunk（**当时实际提交的 API 图**）：

1. 从 `JZL_MiniMaxH3Ref2vaBusOut` 的 `ref_image_0` 反向取到喂它的 `LoadImage` 文件名 —— 即 `<Picture 1>` 的物理来源；
2. 从成片 mp4 取**首窗 5 帧 / 中段 5 帧 / 末窗 5 帧**（`tools/frame_match.py:110` `read_window`）；
3. 用 `to_gray`（`:64-69`，一律缩到 `ANALYZE_W×ANALYZE_H = 160×92`）把参考图与帧统一，算平均绝对差（`mad`，`:72`）；
4. 取每个窗口的最小值。

脚本：`output/issue126-evidence/measure_b.py`；明细：`output/issue126-evidence/b-measurements.json`。

### 为什么不用绝对阈值

`frame_match.py:148-149` 的 `MAD_SAME=2.0` / `MAD_MAYBE=5.0` 来自 2026-09-18 那次**同源视频帧之间**的实测（帧 vs 帧）。这里比的是**参考图 vs 成片帧**，中间隔着一次渲染，绝对刻度不通用。所以下表只比**首 / 中 / 尾三段谁更近**，不套阈值。

中段窗口的作用是**无关帧基准线**：参考图若只当设定图，首、中、尾三段应当一样远。

### 三个误差源（判读时必须带着）

1. **160×92 是 16:9 网格**。10-23 那三份是 **736×1280 竖幅**，被横向拉伸比对，绝对值偏大，**不可与横幅份直接比**。
2. **近静态镜头会让首尾都贴近参考**。a3 那份首 4.50 / 尾 3.33，差 1.35 倍但两边都在噪声量级——不能读成「尾更近」。
3. **参考图未必是构图帧**。角色设定图（10-26 的 00005，`3-A.png`）不存在「首帧/尾帧」问题，三段都远是应然。

## 4. 机制：位置是**声明**出来的，不是模型猜的

官方模板逐字符固定（`src/minimax_h3_prompt/tools/h3_validator.py:92-96`，源头 `references/base-en.txt` 2.1）：

```
I2VA : For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
FL2VA: How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark …
L2VA : How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark …
```

**三套模板里没有「Picture 1 落在末帧」这一种形态**：`<Picture 1>` 要么在 0.00s（I2VA / FL2VA），要么在被点名的任意秒（L2VA，尾帧只是 `S.SS = 末秒` 的特例）。

对照本仓九份：

- **有对齐指令**（10-23 三份，全是 I2VA 的 0.00s）→ 首帧，符合声明；
- **没有对齐指令**（10-26 六份，走 `subject_definitions` 的「referenced by」写法）→ 位置不由提示词指定；其中唯一一份参考图就是精确构图帧的（00006），**模型自己把它放在了起点**。

所以「不是严格锁定首帧」这句话的经验半是对的（无对齐指令时位置不由你我控制），但它给的机制（模型倾向当尾帧）**没有证据支持**。

## 5. 对规格的回灌

| 票 | 该写进去的 | 依据等级 |
|---|---|---|
| **L2/L3 视频词与运镜**（#122） | 想让参考图落在某个时刻，**必须在提示词首行写对齐指令**（I2VA / FL2VA / L2VA 三选一），否则位置不可控 | **官方**（模板）＋ 本仓实测 |
| **L5 关键帧图词**（#124） | 「首尾帧链上一段尾帧起步」这类要求，**不能靠 ref2va 的图摆放**去实现——要用对齐指令显式点名到秒 | 本仓实测 |
| **L6 资产规格**（#125） | 参考图**不是构图帧**时（角色设定图），它不参与时间轴定位；别指望它锚住开场画面 | 本仓实测 |

**一条负面结论也值得记**：社区那条「80% 当尾帧」若被写进任何规格，会把「位置不可控」误诊成「模型偏爱尾帧」，从而把修法引向错的（改提示词内容而非补对齐指令）。
