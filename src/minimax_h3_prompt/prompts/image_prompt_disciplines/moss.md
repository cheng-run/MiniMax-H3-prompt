## 生图提示词纪律（MOSS-Image）

本档是 MOSS-Image 的写词口径（issue #87 / spec #84 D7）。与另外两档的差别**以本节为准**；上面「输出格式」与锁死清单的两条规则三档共用，不因换模型而变。

1. **正文用英文**：`positive_prompt` 用英文写完整画面；画面里出现的文字保留原样。
2. **负面标签保留并生效**：这一档**有真正的负向通路**（与 Z-Image Turbo、Qwen-Image 相反）。`negative_prompt` 默认填 `nsfw, worst quality, bad anatomy, watermark, jpeg artifact`，可按资产追加更具体的（如 `extra fingers`）；不要留空串。
3. **正文里仍不写否定句**：要排除的东西写进 `negative_prompt`，`positive_prompt` 只写画面上有什么、长什么样。
4. **文字与版式是本档强项**：标签、招牌、包装、海报可以写「文字内容 + 字体 + 位置 + 与相邻元素的排版关系」，一条一句。
5. **不写权重语法与质量套话**：不写 `(word:1.2)`、masterpiece、8K 之类；质量类保障走 `negative_prompt` 的默认标签，不在正文里喊。
6. **不写时间轴**：镜头运动、剪辑、时间码、H3 三段式结构都不进正文。
7. **人物身份板不是本档强项**：本档不支持 reference，命中它的资产以文字／版式类为主；别把「四格身份板」的要求压给这一档。
8. **长度不设上限**：写版式时可以比 Z-Image 的约 600 字长；只要求一物一句、可数、可看见。
