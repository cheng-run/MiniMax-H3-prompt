## 生图提示词纪律（Qwen-Image 2.1）

本档是 Qwen-Image 2.1 的写词口径（issue #87 / spec #84 D7）。与 Z-Image Turbo 那一档的差别**以本节为准**；上面「输出格式」与锁死清单的两条规则三档共用，不因换模型而变。

1. **正文用英文**：`positive_prompt` 用英文自然语言写完整画面；专有名词、品牌名与画面里出现的文字保留原样（不音译、不改大小写）。
2. **写长文，约 20 句**：按「主体与身份 → 外观与材质 → 姿态或摆放 → 构图与机位 → 环境 → 光线 → 风格与质感」顺次写下来，句与句衔成一段；不写逗号堆叠的标签串。
3. **固定项原样保留**：锁死清单里的身份特征（发色、服装、标志物）在正文里逐字保留，不换同义词、不改顺序——它们是判偏差的判据。
4. **画面里的文字逐条写**：招牌、包装、标签、海报上的字一条一句，写清「写的是什么字 + 字体气质 + 具体位置」；几条文字不并成一句。
5. **光影单独一句**：光源方向、软硬与色温写成独立句子，不揉进主体或环境的描述里。
6. **不写负面**：这一档与 Z-Image Turbo 同为 CFG=1，负向词是空动作（ADR 0018 第 1 条事实对本档同样成立）；`negative_prompt` 一律留空串，要排除的东西改用正向可见的描述。
7. **不写权重语法与质量套话**：不写 `(word:1.2)`、masterpiece、best quality、8K 之类。
8. **不写时间轴**：镜头运动、剪辑、时间码、H3 三段式结构都不进正文（「四条硬约束」第 1 条对本档同样成立）。

人物（角色参考图与转身板）是本档的强项；透明底 RGBA 也是本档原生支持，但**透明不是本轮的验收条件**——按干净纯色背景写。
