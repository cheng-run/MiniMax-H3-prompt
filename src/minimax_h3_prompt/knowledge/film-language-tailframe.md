# 电影语言词表 · 尾帧编辑半

**尾帧（运镜终点画面）的图生图编辑真源**：写「把这一帧改成本段结束时的画面」时从这里取口径。
它与同级的 `film-language-video.md`（H3 视频正文）和 `film-language-image.md`（静态文生图）
是三份真源，不是一份切片：尾帧写的是**编辑指令**（图 A → 图 B），既不是视频语言，也不是从零生成。

**读者只有一个**：导演台的尾帧写词角色（`director/tailframe.py` 的请求拼装）。
本份管「写什么内容」；「这台模型怎么说」在 `prompts/image_prompt_disciplines/` 的编辑纪律里，
两者冲突时以模型纪律为准。依据等级只留在人读规格里，不进本份。

## 这是编辑，不是重新生成

- 输入图永远是这段的起点画面；正文第一句要说明这是对输入图的编辑，不是重新生成。
- 只写**相对输入图变了什么**：机位与取景、主体位置与姿态、哪些物体出画、哪些物体进画。
- 没被点名的东西一律按输入图保真，不顺手清理、修饰或重画。
- 每一句都要能指回输入图里真实可见的东西；读图结果里没有的，不写。
- 读图结果只提供姿态、背景与光线；人物身份以请求给出的「人物设计基线」为准。

## 终点状态怎么写

- 必须写出 **A → B**：起点地标现在在哪（身后／出画／被谁挡住），以及终点之后人物与
  一个**具名地标**之间是什么**可见关系**（脚下踩在停止线前、正前方是路口那根红绿灯杆、
  左肩与店门招牌对齐）。
- 不写量不出来的程度词：不写「前方几步」「几米」「a few steps away」「several meters」。
- 只写「camera now at B」不算位移——那会让终点画面看起来原地踏步。
- 终点必须落到请求给出的「落定的画面」，不是另起一个镜头。
- 沿途的建筑与店面是同一条街的延续：哪些连续、哪些新出现，不整条街换掉。

## 机位动不动要分叉

- 写正文前先读请求里的「本段视频提示词」，读运镜句判定这一段的机位动没动；
  判不出来时按**在动**处理。
- **机位在动**：写构图迁移（取景、景别、视角怎么变）；保留项**不许**要求背景的相对位置
  保持输入图原样——机位一动，背景相对位置必然变，两条要求互斥。
- **机位不动**：只写主体变化，才允许把背景逐项列进保留项。
- 机位的判定结果只影响「保留什么」，不影响「这是编辑」这条定性。

## 保留区与不变项

- 保留项写成一条毯式句：以输入图中的人物身份与整体画面为准，除上述变化外一律保持输入图原样。
- 身份指向输入图，不逐字罗列五官、发型、配饰的外观：描述得越具体，越容易诱发重新生成。
- 身份漂移要纠正时，写成变换指令里的**编辑动作**（摘下墨镜、露出面部），不写进保留项。
- 光源方向、色温、地面材质可以点名：它们不随运镜改变。
- 会被镜头带出画面的近景物体不进保留项——它们的去向写在变换指令里。
- 机位不动时才允许把建筑、店面、路牌、街道设施逐项列为背景不变项。

## 图里已有主体怎么指称

- 优先用图里看得见的语义名指称（侦探、巡逻车、路口那根红绿灯杆），与读图结果同名。
- 同一主体只指称一次；后文用「他」「它」「那个人物」，不换一个名字指同一个人。
- 只有格式要求必须用 `<Picture N>` / `<Subject N>` 的地方才写编号，其余不写。
- 不把输入图里没有的人、车、招牌写进指令——那等于要求模型凭空补画。

## 落笔前自查

逐条都能一句话判「违反 / 未违反」：

1. 正文第一句说明了「这是对输入图的编辑，不是重新生成」吗？
2. 有没有哪一句写了输入图里看不见的东西？
3. 起点地标现在在哪写了吗？终点与一个具名地标的可见关系写了吗？
4. 有没有出现「几步」「几米」「a few steps away」这类量不出来的程度词？
5. 本段机位在动时，保留项里还要求背景相对位置不变吗？
6. 身份是用毯式句指向输入图，还是逐字罗列了五官与配饰？
7. 锁死清单的每一条，是不是逐字摘自变换指令或保留项声明？
